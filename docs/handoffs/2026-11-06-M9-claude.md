# Handoff — M9 GPU and driver in `meta.json` (claude)

## In plain words
Each new run now writes the GPU name, GPU memory, GPU capability and driver version into `meta.json`.
A new script, `scripts/backfill_hw_meta.py`, can add the same fields to old runs, only on the machine that trained them.
Nothing was trained. X1 and X2 were backfilled after the merge (see Gotchas). Comparisons are unchanged.

## Summary
- `src/cloth_segment/hardware.py`: `gpu_fields(device)` (four fields, all `None` off cuda), `driver_version()` (`nvidia-smi` via `subprocess`, `None` on failure), `backfill_run()`.
- `train.py`: `run()` adds the four fields next to `device` and `gpu_cap_mib`.
- `scripts/backfill_hw_meta.py`: thin CLI over `backfill_run`; takes run folders, has `--dry-run`.
- `tests/test_hardware.py`: no GPU, `torch.cuda` and `subprocess` are mocked.
- No new dependency. Software versions are not recorded: `uv.lock` at the run's `commit` pins them.

## Decisions and why
- New fields: `gpu_name`, `gpu_total_mib`, `gpu_capability` ("major.minor"), `driver_version`. `gpu_total_mib` is unrounded, like `gpu_cap_mib`.
- Backfill only fills a key that is absent. A key that is present, even `null`, is kept.
- Backfill refuses a run whose `host` is not this machine's hostname, or that has no `device`. A `cpu` run gets four nulls. Refusal of one run does not stop the others; the exit code is 1 if any was refused.
- A changed run gets `hw_backfilled: true`. A run with nothing to add is not marked.
- This edits `meta.json` of finished runs, which D7 normally forbids. The task allows it for these fields only, through this script.
- Not changed: `META_FIELDS` in `compare.py` and other contracts in `CONTRIBUTING.md` section 4.

## Gotchas
- Backfill reads the GPU and driver installed now. The driver may be newer than the one the run used, and the host check cannot tell. That is why `hw_backfilled` exists: treat those values as "this machine today".
- For a `cuda:N` run, backfill reads GPU N; for plain `cuda` it uses the current device.
- With several GPUs `nvidia-smi` prints one line each; the first line is used (one driver per machine).
- `nvidia-smi` is called with a 30 s timeout.
- X1 (`20261105-0323-7b1798b-unet-r34`) and X2 (`20261105-1307-1acb88f-unet-r34`) were backfilled after the PR merged, on `METAVERSE-05` (their `host`), by request. Dry run first, then the real run. Both got RTX 4070, 12281.5 MiB, capability 8.9, driver 560.94, `hw_backfilled: true`. The driver is the one installed at backfill time.
- For other runs, do `--dry-run` first: `uv run python scripts/backfill_hw_meta.py --dry-run runs/<run>`.
