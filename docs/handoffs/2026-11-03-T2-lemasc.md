# Handoff — T2 Shared label set and converters

**Status:** done. Implements the kickoff draft plus the T1 changes (DFMM
leggings → footwear, belt → ignore).

## What exists

- `src/cloth_segment/data/labels.py`: the single source of the label set.
  - `SHARED_CLASSES` (12), `IGNORE = 255`, `PALETTE`, `colorize()`.
  - `MAPPING_BY_NAME`: raw name → shared name per dataset, with a comment on
    each non-obvious choice. `MAPPING` (raw ID → shared ID) is derived from it,
    and the import fails if any raw label is unmapped.
  - `convert(mask, dataset)`: lookup-table mapping; raises
    `UnknownLabelError` on any value outside the raw label set, and rejects
    3-D (RGB) masks.
  - `LABEL_VERSION = "labels-v1"`, `label_spec()`, `label_hash()`.
- `scripts/prepare_masks.py`: converts all 86,443 masks (~25 s) into
  `data/masks/labels-v1/` on the shared mount (484 MB):
  - `<dataset>/<split>/<id>.png`: mode `L`, same size as the image.
  - `stats.csv`: per pair, `h`, `w` and the pixel count per shared class
    (`c0`–`c11`, `c255`).
  - `labels.json`: spec + hash `5e848d807d92`.
  - `DONE`.
  
  It builds in a temp folder and renames at the end. Rerunning with the same
  hash is a no-op; with a changed mapping it refuses to overwrite.
- `tests/test_labels.py`: coverage, every class present in every dataset,
  each T1 decision, left/right merge, flip equivariance, unknown values, RGB
  rejection (27 tests total pass).
- The T1 notebook now imports `MAPPING` instead of its own draft copy.

## Verification

- For every pair, the per-class counts in `stats.csv` equal the counts
  derived from the T1 raw scan through `MAPPING` (0 mismatches in 86,443), and
  every mask size equals its image size.
- 200 random output PNGs re-read: `uint8`, 2-D, values ⊆ {0–11, 255}, counts
  match `stats.csv`.
- Visual check of colourised masks from all three datasets looked correct.

## For T3 / T4

- Use `data/masks/labels-v1/` masks with the original images from
  `datasets/` (paths via `sources.list_pairs`). Do not re-convert in the
  loader.
- `stats.csv` covers what T3 needs without re-reading masks: empty masks
  (LIP: 105 with only background), class frequencies and weights (train split
  only), and per-image class presence for stratifying the DFMM split.
- The data version for runs (D7) should combine `label_hash()` with the T3
  split/manifest hash.
- To change the mapping: edit `MAPPING_BY_NAME`, bump `LABEL_VERSION`, rerun
  the script. The old folder stays for runs that used it.

## Limitations to report

- CIHP has no jumpsuit class: its jumpsuits are labelled as upper + pants (or
  dress), while LIP/DFMM call them one-piece.
- Belts are garment pixels in LIP/CIHP and ignored in DFMM, so models learn
  "belt = garment" from LIP/CIHP only.
- DFMM gives almost no accessory pixels (0.02%), so accessory is learnt mostly
  from LIP/CIHP.
