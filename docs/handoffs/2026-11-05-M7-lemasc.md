The iteration budget for the DeepLabV3+ and SegFormer-B2 runs (X3, X4) is **40,000 iterations**, the same as the U-Net runs. This is decided; do not wait for a 40k / 80k vote.

## Decisions and why
- **40k, not 80k.** Reasons, from the T6 retrain report: 80k does not remove the run-to-run spread (about 0.01 mIoU between two U-Net runs with the same config); the late gain at 40k is partly the learning rate reaching 0, so 80k cannot be guessed from the curve; every later run costs about twice the GPU time at 80k; the 11-class test mIoU was stable between the two runs (0.0008 apart).
- **Why now:** X3/X4 are `todo`, and a collaborator who picks one up would wait for this answer.
- **The known cost:** at 40k, `accessory` is only starting to be learned (retrain LIP val 0.0291, DFMM 0.0000), so a model comparison may partly reflect who learns `accessory` in time. The report's conditions still apply: T9 reports 11-class mIoU next to 12-class, and `accessory` separately; differences below about 0.013 between models are not separable from run-to-run spread.

No new numbers. The evidence is in the T6 retrain report (runs `20261105-0323-7b1798b-unet-r34` and `20261105-1307-1acb88f-unet-r34`).

## Gotchas
- Reopen trigger, exactly: X3 `best.pt` at step 40000 again. A model whose best step is earlier than 40000 does not trigger it.
- If it triggers and the budget moves to 80k, `train.iters` is a shared comparison field (D5, `open`), so U-Net and the finished X3 run must be re-run too (a new config hash, D7). That is why the decision is cheapest now.
- Running X3 and X4 at 40k does not stop anyone from also running a longer run later as a separate experiment; it just is not the comparison.
