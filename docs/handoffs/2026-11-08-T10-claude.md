## Decisions and why
- **แบ่งสาม zone และใช้ระยะขอบตามสัดส่วนเส้นทแยงมุม** ภาพสามชุดมีขนาดต่างกันมาก (LIP ด้านสั้นราว 180 px, DFMM 750 px) ระยะคงที่จะไม่ยุติธรรม ลองสามระยะเพื่อดูว่าข้อสรุปไม่ขึ้นกับค่าที่เลือก
- **"ให้ป้ายผิดทั้งชิ้น" = พื้นที่ต่อเนื่อง (8 ทิศ) ของคลาสหนึ่งใน ground truth ที่ส่วนใหญ่ถูกทายเป็นคลาสอื่น** เข้าใจง่ายและตอบคำถามว่าผิดเพราะเลือกป้ายผิดหรือขอบไม่คม
- **zone รวมกันต้องเท่ากับ `metrics.json`** ใช้เป็นตัวตรวจ: X2 และ X3 ตรงทุกช่อง X4 ต่างเล็กน้อยเพราะคนละ GPU (เหมือน M10)
- **notebook review ใหม่แทนการแก้ notebook M10** notebook M10 เป็นบันทึกของ M10 และครึ่งแรกเป็นการวิเคราะห์เฉพาะ M10 จึงไม่แตะ
- **ไม่ให้ผู้อ่านรอบสองเห็นคำตัดสินเดิมและว่ารูปไหนมาจากกลุ่ม "แย่สุด"** เพื่อไม่ให้เอนตาม
- **เก็บทั้งสามขั้นใน git** (รอบแรก, รอบสอง AI, ฉบับแก้) เพราะความเห็นต่างเองเป็นผล: ทั้ง 6 รูปที่ยังต่างกันเป็นรูปครอป
- **d5 = ข้อจำกัด** maintainer ตัดสิน ไม่แก้ label และไม่เทรนใหม่

## Results / findings
ตัวเลขจาก run X2 `20261105-1307-1acb88f-unet-r34`, X3 `20261105-2050-f4e2ffe-deeplabv3p-r50`, X4 `20261105-2220-ac9a26b-segformer-b2`

- พิกเซลที่ผิดอยู่ที่ขอบ (1%): LIP 40–42%, CIHP 57–59%, DFMM 71–74% ทั้งสามโมเดลใกล้กัน
- เสื้อผ้า (X4): 31–67% ของที่ผิดเป็นการให้ป้ายผิดทั้งชิ้น ผม หน้า ผิว: 75–100% อยู่ที่ขอบ
- ถ้าไม่นับขอบ X4 ยังนำเท่าเดิมบน LIP/CIHP แต่บน DFMM นำ X3 แค่ +0.014 (จาก +0.039) และ X3 แย่ที่สุดที่ขอบ
- คนตัวเล็ก (< 20% ของภาพ) บน LIP: mIoU 0.28–0.31 เทียบกับ 0.62–0.67 ของคนตัวใหญ่ ความละเอียดของภาพมีผลน้อย
- CIHP `dress`: 166 จาก 936 รูป (17.7%) ทุกโมเดลหาเจอไม่ถึง 10% ใน 12 รูปสุ่ม label ถูกหรือก้ำกึ่ง 11 รูป (ทั้งสองรอบ) คำตัดสินตรงกัน 18/24

## Gotchas
- `scripts/error_zones.py` ไม่เขียนทับ ถ้าไฟล์ใน `data/analysis/T10/zones/` มีอยู่แล้วจะข้าม ใช้ `--wait` เพื่อรอ GPU lock
- notebook review ต้องรันด้วย `uv run marimo edit notebooks/review/visual_review.py -- --config configs/review/<task>.yaml` (ต้องมี `--`) ทุกคำตัดสินบันทึกลงไฟล์ทันที
- ตัวเลขเพิ่มในรายงานมาจากไฟล์ที่สร้างเท่านั้น เช่น 166/936 อยู่ในไฟล์ตารางหัวข้อ "Images where every run finds under 10%"
- `pgrep -f scripts/error_zones.py` ใน shell จะเจอ command ของตัวเอง ใช้ PID หรือดูหน่วยความจำ GPU แทน
