# Handoff — T6 U-Net (ResNet-34), model code (amonwan)

**Status:** `doing`. โค้ดโมเดลเสร็จแล้ว การเทรนจริงรอ T4 (data loader) และ
T5 (training pipeline) merge ก่อน

## In plain words

1. เพิ่ม U-Net และระบบเลือกโมเดลจากชื่อใน config ส่วน encoder (ส่วนที่ย่อรูปเพื่อหาลักษณะเด่น) เป็น ResNet-34 ที่เรียนจาก ImageNet มาแล้ว ส่วน decoder (ส่วนที่ขยายผลกลับเป็นขนาดรูป) เริ่มเรียนใหม่
2. เรียก `build_model(cfg)` ซึ่งเลือก builder (ฟังก์ชันที่สร้างโมเดล) ตามชื่อใน config ได้โมเดลที่รับรูปขนาดใดก็ได้ และคืน logits (คะแนนดิบของ 12 คลาสต่อพิกเซล ยังไม่ผ่าน softmax) ขนาดเท่ารูปเดิม
3. ทดสอบบน CPU ผ่านแล้ว ยังไม่ได้เทรน รอ T4/T5

## Summary

- `src/cloth_segment/models/__init__.py`
  - `build_model(cfg)` เลือกโมเดลจาก `cfg["model"]["name"]` แล้วส่ง key อื่นใต้
    `model:` เป็น argument ให้ builder (ฟังก์ชันที่สร้างโมเดล)
  - `register(name)` เป็น decorator สำหรับลงทะเบียน builder
  - `count_parameters(model, trainable_only=False)`
- `src/cloth_segment/models/wrappers.py`: `PadToMultiple(net, multiple)`
  เติมขอบขวาและล่างด้วย 0 ให้ H, W หารด้วย `multiple` ลงตัว รันโมเดล
  ถ้า output เล็กกว่ารูปเข้าจะขยายแบบ bilinear แล้ว crop กลับเป็นขนาดเดิม
- `src/cloth_segment/models/unet.py`: `unet_r34` =
  `smp.Unet("resnet34", classes=NUM_CLASSES, activation=None)` ห่อด้วย
  `PadToMultiple(32)`
- `configs/unet_r34.yaml`: มีแค่ `model.name: unet_r34` และ `model.pretrained: true`
- `tests/test_models.py`: 25 test รันบน CPU ไม่ต้องโหลด weight (ใช้
  `pretrained: False`)
- dependency ใหม่: `segmentation-models-pytorch>=0.6.0` (lock ไว้ที่ 0.6.0 ใน
  `uv.lock` ดึง `timm==1.0.31`
  มาด้วย) ทีมอนุญาตแล้ว torch ยังเป็น 2.14.1

Interface ของทุกโมเดล: รับ `[B, 3, H, W]` ที่ normalise แบบ ImageNet แล้ว
คืน logits `[B, 12, H, W]` ไม่มี softmax

## Decisions and why

- **smp แทนการเขียน decoder เอง:** ลดความเสี่ยงบั๊กใน decoder ที่เขียนเอง
  encoder ไม่ใช่ตัวเดียวกัน ตาม PLAN U-Net (T6) ใช้ ResNet-34 และ DeepLabV3+
  (T7) ใช้ ResNet-50 ความยุติธรรมตาม D5 มาจากการใช้ encoder ที่ pretrained บน
  ImageNet จากแหล่งเดียวกัน (smp) และ pipeline เดียวกัน (data, split, ความละเอียด
  ภาพ, augmentation, จำนวน iteration) ขนาดโมเดลจึงต่างกัน ต้องรายงานจำนวน
  พารามิเตอร์ (จาก `count_parameters`) คู่กับผลทุกครั้ง
- **Pad แล้ว crop แทนการ resize:** smp.Unet ต้องการ H, W ที่หาร 32 ลงตัว
  การ pad ไม่เปลี่ยนพิกเซลเดิม จึงได้ logits ตรงตำแหน่งกับ mask
  pad ด้วย 0 เพราะหลัง ImageNet normalisation ค่า 0 คือสีเฉลี่ย
- **Normalisation อยู่ใน data transforms (T4) ไม่ได้อยู่ในโมเดล** ตาม checklist ใน
  kickoff handoff ใช้ค่าเดียวกันกับทุกโมเดล
- **`NUM_CLASSES` มาจาก `data/labels.py`** ไม่ได้อยู่ใน config จึงตรงกับ label set เสมอ
- **Key ที่ไม่รู้จักใต้ `model:` จะ raise `TypeError`** ชื่อโมเดลที่ไม่รู้จัก
  (รวมถึง `null` ใน `base.yaml`) จะ raise `ValueError` เพื่อไม่ให้ config
  ที่พิมพ์ผิดรันผ่านไปเงียบ ๆ

## Results / findings

จำนวนพารามิเตอร์ (`unet_r34`, 12 class, นับบน CPU ด้วย `count_parameters`):

| ส่วน | พารามิเตอร์ |
|---|---|
| ทั้งหมด | 24,437,964 |
| encoder (ResNet-34 ไม่รวม fc) | 21,284,672 |
| decoder | 3,151,552 |
| segmentation head | 1,740 |
| decoder + head | 3,153,292 |

ทุกพารามิเตอร์ trainable (24,437,964) ตัวเลขนี้เท่ากันทั้ง `pretrained` true
และ false

ทดลองโหลด weight ImageNet (`pretrained: true`) บน CPU 1 ครั้ง (2026-11-04)
ไม่ใช้ GPU:

- **สำเร็จ:** build ใช้เวลา 4.5 วินาที รวมการดาวน์โหลด
- weight ต่างจากค่าสุ่มตอนเริ่มต้น และ running mean ของ BatchNorm ไม่เป็นศูนย์
  แปลว่าโหลด weight จริง
- forward รูป 100×75 ได้ `(1, 12, 100, 75)`
- weight มาจาก Hugging Face repo `smp-hub/resnet34.imagenet` เก็บที่
  `~/.cache/huggingface/hub/models--smp-hub--resnet34.imagenet` (84 MB)
  cache นี้แยกตาม Linux user ไม่อยู่ใน `datasets/`, `data/` หรือ `runs/`

ruff และ pytest: ผ่านทั้งหมด 62 test (หลัง merge main)

ยังไม่มีผลการเทรน

## Gotchas

- smp.Unet ไม่รับ H, W ที่หาร 32 ไม่ลงตัว ให้สร้างโมเดลผ่าน `build_model`
  เสมอ (มี `PadToMultiple` ห่ออยู่แล้ว) อย่าเรียก `smp.Unet` ตรง ๆ
- โมเดลข้างในเข้าถึงได้ที่ `model.net` (มี `.encoder`, `.decoder`,
  `.segmentation_head`) เช่น ถ้า T5 อยากตั้ง learning rate ของ encoder แยก
- สมาชิกแต่ละคนบนเครื่องกลางจะดาวน์โหลด weight เองครั้งแรก (84 MB) เพราะ cache
  อยู่ใน home ของแต่ละคน ถ้าเครื่องเทรนออกเน็ตไม่ได้ ให้ดาวน์โหลดไว้ก่อน
  แล้วตั้ง `HF_HUB_OFFLINE=1`
- Checkpoint ของ U-Net ที่เทรนแล้วจะมี prefix `net.` ใน state dict เพราะมี wrapper ห่อ
