# Handoff — T9 Evaluation: สามโมเดลบน test set (claude)

## In plain words
ทำตาราง กราฟ และรูปตัวอย่างเทียบสามโมเดลบน test set ของ LIP, CIHP และ DFMM จากไฟล์ผลที่มีอยู่ ไม่ได้เทรนใหม่ และไม่ได้แก้ eval protocol
SegFormer-B2 (X4) ดีที่สุดชัดเจน (mIoU ไม่นับ `accessory` เฉลี่ยสามชุด 0.724 เทียบกับ X3 0.686 และ X2 0.679) และดีกว่าทุกคลาสในทุก test set ส่วน X3 ดีกว่า X2 นิดเดียว
คะแนนเพิ่มตาม M10 (d1, d2) ทำครบแล้ว ไม่เปลี่ยนลำดับ ขั้นต่อไปคือ T10 รายงานเต็มอยู่ที่ `docs/reports/2026-11-07-T9-evaluation.md`

## Summary
- `src/cloth_segment/results.py`: อ่าน `metrics.json` และไฟล์ breakdown ของ M10 แล้วคำนวณตาราง คะแนนเพิ่ม (สร้าง confusion matrix ใหม่จาก raw class แล้วตัดบาง raw class ออก) และ paired bootstrap รวมถึงฟังก์ชันวาดกราฟ ใช้ `evaluate.scores` ตัวเดิมคิด IoU/Dice
- `scripts/t9_results.py` + `configs/report/t9.yaml`: เขียน `docs/reports/2026-11-07-T9-results.json`, `...-T9-tables.md` และกราฟ PNG ใน `docs/reports/figures/T9/` ไม่ใช้ GPU ใช้เวลาราว 6 วินาที
- `configs/review/t9.yaml`: ใช้ `scripts/review_predictions.py` (ของ M10) เลือก 8 รูปต่อ test set และทาย mask ด้วย GPU (ถือ GPU lock ราว 9 วินาที) เก็บไว้ที่ `data/review/T9/`
- `scripts/t9_qualitative.py` + `review.image_miou` / `review.comparison_grid`: วาดรูปเปรียบเทียบ (รูปจริง | ground truth | X2 | X3 | X4) เป็น JPEG ใน `data/review/T9/figures/` บน shared mount
- เทสต์: `tests/test_results.py` (ใหม่) และเพิ่มใน `tests/test_review.py` ใช้ข้อมูลสังเคราะห์ ไม่ต้องใช้ dataset หรือ GPU

## Decisions and why
- **mIoU หลักไม่นับ `accessory`** ตามที่ M6 ตัดสินไว้ ตารางแสดง 12 คลาสคู่กันด้วย
- **ค่าเฉลี่ยสามชุดให้น้ำหนักเท่ากัน** ไม่รวมพิกเซล (M3)
- **คำนวณนอก `evaluate.py`** (frozen) ทั้งคะแนนเพิ่มและ bootstrap ไม่มี contract ไหนถูกแก้
- **คะแนนเพิ่มคิดจาก matrix ที่สร้างใหม่ทั้งก่อนและหลังตัด** ตามวิธีใน M10 สำหรับ X4 matrix ที่สร้างใหม่ต่างจาก `metrics.json` ไม่เกิน 0.00044 IoU (วัดใหม่บนอีก GPU)
- **Bootstrap แบบ paired สุ่มรูป 2000 ครั้ง** ทุกโมเดลใช้รูปชุดเดียวกัน เพื่อให้ช่วงของความต่างแคบและถูกต้อง เพิ่มเข้ามาเพราะมีโมเดลละ 1 run ต้องการอย่างน้อยหนึ่งตัวบอกว่าความต่างใหญ่กว่า noise ของ test set ไหม
- **รูปตัวอย่างเลือกจากเครื่องมือของ M10** (สุ่ม 5 + แย่สุดตาม X4 3 รูปต่อชุด) ไม่ได้เขียนตัวเลือกรูปใหม่
- **รูปตัวอย่างอยู่บน shared mount ไม่อยู่ใน git** เพราะมีภาพจาก dataset (CONTRIBUTING หัวข้อ 8–9) กราฟตัวเลขทั้งหมด commit ไว้ใน `docs/reports/figures/T9/` และไม่มีภาพจาก dataset
- **ไม่ใช้ Jupyter notebook** (CONTRIBUTING หัวข้อ 8 แนะนำสำหรับ analysis) ใช้สคริปต์ที่เขียนไฟล์ผลแทน ผลออกมาเหมือนเดิมทุกครั้ง (ตรวจด้วย md5 แล้ว) และตัวเลขในรายงานอ้างอิงไฟล์ JSON ได้ตรง ๆ

## Results / findings
ทุกตัวเลขมาจาก run `20261105-1307-1acb88f-unet-r34` (X2), `20261105-2050-f4e2ffe-deeplabv3p-r50` (X3), `20261105-2220-ac9a26b-segformer-b2` (X4), `eval-v2`, `splits-v2-d023252b81d9`

| test set | X2 | X3 | X4 |
|---|---|---|---|
| LIP | 0.5924 | 0.6071 | **0.6399** |
| CIHP | 0.6185 | 0.6262 | **0.6682** |
| DFMM | 0.8257 | 0.8245 | **0.8635** |
| เฉลี่ย | 0.6789 | 0.6859 | **0.7239** |

(mIoU ไม่นับ `accessory`)

- X4 − X2 = +0.045 (95%: +0.041 ถึง +0.049), X4 − X3 = +0.038 (+0.034 ถึง +0.042), X3 − X2 = +0.007 (+0.004 ถึง +0.010) บน DFMM X3 กับ X2 ไม่ต่างกัน (−0.001, −0.010 ถึง +0.007)
- d1 (LIP `dress` ไม่นับ jumpsuit): IoU ของ X2 +0.018 แต่ของ X3 −0.014 และของ X4 −0.005 เพราะ X3/X4 หา jumpsuit เป็น `dress` เจอมากกว่า IoU เฉลี่ยของคลาส การตัดออกจึงตัดพิกเซลที่ทายถูกไปด้วย สรุปคือ jumpsuit ไม่ใช่สาเหตุหลักที่ LIP `dress` ต่ำ ชุดเดรสจริงก็หาเจอแค่ 55–60%
- d2 (CIHP `footwear` ไม่นับ socks): +0.039 / +0.026 / +0.014 (X2 / X3 / X4) mIoU ขยับไม่เกิน +0.005
- ความสับสนหลักเหมือนกันทุกโมเดล: skirt ↔ pants/dress, dress → upper, outer → upper, footwear → background X4 ลดทุกคู่ลง แต่ไม่หายไป

## Gotchas
- `per_image_shared.csv` และ `raw_confusion.json` ของ X4 มาจากการวัดใหม่บน RTX 4070 (M10) ไม่ใช่ RTX 3060 ที่เขียน `metrics.json` ตาราง "Cross-check" ในไฟล์ตารางแสดงความต่าง
- `scripts/review_predictions.py` ไม่เขียนทับ: ถ้า `data/review/T9/samples.csv` มีอยู่แล้วแต่ไม่ตรง จะหยุด ต้องเปลี่ยน `out_dir` ถ้าจะเลือกรูปใหม่
- ตัวเลข mIoU ใต้รูปตัวอย่างเป็นของรูปเดียว แกว่งมาก (คลาสที่มีไม่กี่พิกเซลมีน้ำหนักเท่าคลาสใหญ่)
- จุดตรงกลางในกราฟ `miou_by_test_set.png` คือคะแนนทางการ ส่วนช่วงมาจากข้อมูลที่คำนวณใหม่ (สำหรับ X4) จึงตัดความยาวที่ติดลบออก (clip) ในข้อมูลจริงไม่เกิดกรณีนี้
