# เกณฑ์การให้คะแนนโปรเจกต์ (คะแนนเต็ม 15 คะแนน)

## 1. ความยากของงาน — 4 คะแนน

ให้คะแนนตามประเภทงานที่กลุ่มดำเนินการ โดยเลือกเกณฑ์สูงสุดที่เข้าเงื่อนไขเพียงรายการเดียว **ไม่รวมคะแนนข้ามประเภท**

| ประเภทงาน | คะแนน | ลักษณะงาน |
|---|---|---|
| **Multi-task Learning หรือ Video Analysis** | **4** | แบบจำลองเรียนรู้ร่วมกันตั้งแต่ 2 งานขึ้นไป หรือวิเคราะห์วิดีโอโดยใช้ข้อมูลความสัมพันธ์ระหว่างเฟรม |
| **Image Segmentation หรือ Pixel Regression** | **3** | จำแนกประเภทในระดับพิกเซล หรือทำนายค่าต่อเนื่องในระดับพิกเซล เช่น แผนที่ความลึก |
| **Object Detection หรือ Image Regression** | **2** | ตรวจจับตำแหน่งและประเภทวัตถุ หรือทำนายค่าตัวเลขระดับภาพ เช่น อายุหรือค่าการวัด |
| **Multilabel Image Classification** | **1.5** | ทำนายหลายป้ายกำกับต่อภาพ โดยภาพหนึ่งภาพอาจมีหลายป้ายกำกับพร้อมกัน |
| **Multiclass Image Classification** | **1** | จำแนกภาพเป็นหนึ่งคลาสจากหลายคลาสที่กำหนด |

### เงื่อนไขการให้คะแนนความยาก

- ต้องมีแบบจำลองที่ทำงานได้และมีผลประเมินสอดคล้องกับประเภทงานที่เลือก การระบุประเภทงานในข้อเสนอเพียงอย่างเดียวไม่ถือว่าเข้าเกณฑ์
- **Multi-task Learning:** ต้องมีอย่างน้อย 2 งานที่เรียนรู้ร่วมกันในแบบจำลอง และรายงานผลประเมินแยกแต่ละงาน การเปรียบเทียบหลายแบบจำลองสำหรับงานเดียวไม่ถือเป็น Multi-task
- **Video Analysis:** ต้องใช้ข้อมูลเชิงเวลา หรือความสัมพันธ์ระหว่างเฟรมในการวิเคราะห์ การนำวิดีโอมาแยกเป็นภาพแล้วทำนายแต่ละเฟรมอย่างอิสระไม่เข้าเกณฑ์ 4 คะแนน โดยจะพิจารณาตามประเภทงานภาพที่ทำจริง
- หากไม่มีแบบจำลองหรือผลประเมินที่ตรวจสอบได้ ให้ **0 คะแนน** ในส่วนนี้

## 2. รูบริกประเมินคุณภาพงาน — 11 คะแนน

| ประเด็นประเมิน | ดีมาก | ดี | พอใช้ | ไม่มีหลักฐาน |
|---|---|---|---|---|
| **การกำหนดปัญหาและเตรียมข้อมูล (2 คะแนน)** | **2:** ปัญหาและวัตถุประสงค์ชัดเจน ระบุแหล่งข้อมูล เตรียมและแบ่งข้อมูลเหมาะสม ป้องกันข้อมูลจากเดียวกันปะปนข้ามชุด | **1.5:** ปัญหาและข้อมูลเหมาะสม แต่รายละเอียดการเตรียมหรือแบ่งข้อมูลยังไม่ครบ | **1:** ปัญหายังไม่ชัด หรือการเตรียมและแบ่งข้อมูลมีข้อบกพร่องสำคัญ | **0:** ไม่มีคำอธิบายปัญหาหรือหลักฐานการเตรียมข้อมูล |
| **การพัฒนาแบบจำลองและการทดลอง (2 คะแนน)** | **2:** แบบจำลองทำงานได้ อธิบายวิธีการและการตั้งค่าได้ มีการเปรียบเทียบอย่างน้อย 3 รูปแบบอย่างเป็นธรรม | **1.5:** แบบจำลองทำงานได้และมีการเปรียบเทียบ แต่รายละเอียดหรือเหตุผลยังไม่ครบ | **1:** ทดลองเพียงรูปแบบเดียว หรือโค้ดทำงานได้บางส่วนและอธิบายวิธีการได้จำกัด | **0:** ไม่มีหลักฐานการพัฒนาและทดลอง |
| **การประเมินและวิเคราะห์ผล (2 คะแนน)** | **2:** ใช้ตัวชี้วัดเหมาะสม ประเมินบนชุดทดสอบที่แยกไว้ เปรียบเทียบผล พร้อมวิเคราะห์ตัวอย่างที่ถูกต้อง ผิดพลาด และข้อจำกัด | **1.5:** ประเมินผลได้เหมาะสม แต่การเปรียบเทียบหรือวิเคราะห์ข้อผิดพลาดยังไม่ครบ | **1:** มีผลประเมินบางส่วน แต่ตัวชี้วัดหรือวิธีทดสอบยังไม่เหมาะสม และวิเคราะห์ผลได้น้อย | **0:** ไม่มีผลประเมินที่ตรวจสอบได้ |
| **ความสวยงามและการออกแบบสื่อ (2 คะแนน)** | **2:** สไลด์เป็นระเบียบ สีและรูปแบบสม่ำเสมอ ตัวอักษรอ่านง่าย ภาพ ตาราง และกราฟชัดเจน มีป้ายกำกับครบ | **1.5:** สื่ออ่านเข้าใจได้ แต่บางส่วนแน่นเกินไปหรือรูปแบบไม่สม่ำเสมอ | **1:** สื่อพออ่านได้ แต่ตัวอักษรเล็ก ภาพไม่ชัด หรือจัดวางจนติดตามเนื้อหาได้ยาก | **0:** ไม่มีสื่อ หรือสื่อส่วนใหญ่ไม่สามารถอ่านและตีความได้ |
| **การนำเสนอและตอบคำถาม (3 คะแนน)** | **3:** นำเสนอเป็นลำดับ เข้าใจง่าย อยู่ในเวลาที่กำหนด อธิบายงานที่รับผิดชอบและตอบคำถามได้ถูกต้อง | **2:** นำเสนอเข้าใจได้ อธิบายหน้าที่และตอบคำถามหลักได้ แต่ยังติดขัดบางส่วน | **1:** อ่านตามสไลด์เป็นหลัก อธิบายงานหรือตอบคำถามได้จำกัด และการมีส่วนร่วมไม่ชัดเจน | **0:** ไม่ร่วมการนำเสนอ และไม่มีหลักฐานเพียงพอให้ประเมินความเข้าใจหรือการมีส่วนร่วม |

## ตัวอย่างตัวชี้วัดที่เลือกใช้

| ประเภทงาน | ตัวชี้วัดที่เหมาะสม |
|---|---|
| Image Classification | Precision, Recall, F1-score และ Confusion Matrix; ใช้ Accuracy ประกอบได้ |
| Object Detection | mAP, Precision และ Recall โดยระบุเกณฑ์ IoU ที่ใช้ |
| Image Segmentation | Dice Score หรือ IoU พร้อมตัวอย่างภาพเปรียบเทียบกับ Ground Truth |
| Image Regression | MAE หรือ RMSE พร้อมระบุหน่วยของค่าที่ทำนาย |
| Video Analysis | เลือกตามผลลัพธ์ของงาน เช่น F1-score สำหรับจำแนกกิจกรรม หรือ mAP สำหรับตรวจจับวัตถุ |

## สิ่งที่ต้องส่ง

- **โค้ด** พร้อมคำอธิบายวิธีใช้งาน แหล่งข้อมูล และการตั้งค่าที่จำเป็น
- **สไลด์นำเสนอ** ครอบคลุมเกณฑ์การให้คะแนนข้างต้น
