# รายงานการเทรน: DeepLabV3+ ResNet-50 (X3)

## In plain words
เทรน DeepLabV3+ R50 ครบ 40,000 iteration ด้วย config ร่วมเดียวกับ U-Net (X2) lr 1e-4 เท่ากัน
ผล test mIoU: LIP **0.5764**, CIHP **0.5875**, DFMM **0.7901** (eval-v2, `best.pt` step 40000) สูงกว่า U-Net (X2) ทุกชุด
ส่วนต่างส่วนใหญ่มาจาก `accessory` ถ้าไม่นับ `accessory` ต่างกันแค่ +0.0070 ซึ่งยังแยกจากความแกว่งระหว่างรันไม่ได้ชัด
`best.pt` อยู่ที่ step 40000 ตรงกับเงื่อนไขเปิด budget ใหม่ของ M7 จึงต้องแจ้ง lemasc

ตัวเลขทุกตัวมาจากไฟล์ใน run folder (`meta.json`, `log.jsonl`, `eval/eval-v2/*/metrics.json`) ผ่าน `scripts/compare_runs.py` ไม่มีค่าประมาณ ยกเว้นที่เขียนว่า "ประมาณ"

## การตีความ
- **12 คลาส X3 สูงกว่า X2 ชัด** (test เฉลี่ย +0.0266, val เฉลี่ย +0.0293) มากกว่าเกณฑ์ประมาณ 0.013 ใน M7 (ความต่างระหว่าง 2 รันของ U-Net ที่ config เดียวกัน)
- **ส่วนต่างส่วนใหญ่มาจาก `accessory`** ไม่นับ `accessory` ต่างกัน +0.0070 ต่ำกว่าเกณฑ์ 0.013 แต่สูงกว่าความต่างแบบ 11 คลาสระหว่าง 2 รันของ U-Net (0.0008)
  เกณฑ์สองตัวนี้ให้คำตอบต่างกัน และแต่ละโมเดลมีแค่ 1 รัน (U-Net มี 2) จึงยังสรุปไม่ได้ว่า 11 คลาส X3 ดีกว่าจริง
- **X3 เรียน `accessory` ได้เร็วกว่ามากในรันนี้** ข้อกังวลของ M7 ("ที่ 40k ผลอาจขึ้นกับว่าโมเดลไหนเริ่มเรียน `accessory` ทัน") เกิดขึ้นจริงในการเทียบนี้
  ยังไม่รู้ว่าเป็นเพราะสถาปัตยกรรม (เช่น ASPP ที่ดูหลายระยะ) หรือ seed เพราะมีรันเดียว
- **ที่ 40k ยังไม่อิ่มตัว** val ขึ้นทุก check รวมถึง check สุดท้าย และ `best.pt` เป็น step สุดท้าย
  ส่วนหนึ่งของการขึ้นช่วงท้ายมาจาก lr ที่ลดลงเป็น 0 (เหมือน X2) จึงเดาผลที่ 80k จากกราฟนี้ไม่ได้
- ResNet-50 มีพารามิเตอร์มากกว่า U-Net R34 ประมาณ 9% (26.7M กับ 24.4M) และเทรนช้ากว่าประมาณ 6% (4,384.8 กับ 4,148.7 วินาที)

## เงื่อนไขของ M7
M7 บอกว่า "ถ้า X3 `best.pt` อยู่ที่ step 40000 อีก ให้แจ้ง lemasc" **เงื่อนไขนี้เกิดขึ้นแล้ว** (`best_step` 40000)
ไม่ได้เปลี่ยน budget เอง ให้ lemasc ตัดสิน ถ้าเปลี่ยนเป็น 80k ต้องเทรนใหม่ทั้ง X2 และ X3 (config hash ใหม่)

## สิ่งที่ยังไม่รู้
- ความแกว่งระหว่างรันของ DeepLabV3+ (มีรันเดียว)
- `accessory` ที่เรียนได้เร็วขึ้นมาจากสถาปัตยกรรมหรือ seed
- ทำไม DFMM 11 คลาสของ X3 ต่ำกว่า X2 เล็กน้อยหลายคลาส ทั้งที่ LIP และ CIHP สูงกว่า (ยังไม่ได้ดูภาพ)

## งานต่อ
1. **lemasc:** ตัดสินว่าจะเปิด budget ใหม่หรือไม่ (เงื่อนไข M7 เกิดแล้ว)
2. **X4:** SegFormer-B2 40k (ถ้า budget ไม่เปลี่ยน) หลัง T8
3. **T9:** ตารางเทียบ 3 โมเดล รายงาน 11 คลาสคู่กับ 12 คลาส และ `accessory` แยก
4. ถ้ามีเวลา GPU: รัน X3 ซ้ำด้วย seed อื่น เพื่อดูว่า `accessory` เรียนเร็วทุกครั้งหรือไม่
5. ใช้ `scripts/accessory_by_raw_class.py` กับรันนี้ (M6) เพื่อดูว่า `accessory` ที่ถูกเป็นคลาสดิบอะไร
