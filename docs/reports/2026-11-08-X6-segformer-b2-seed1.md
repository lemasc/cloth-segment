# รายงานการเทรน: SegFormer-B2 seed 1 (X6) และการเทียบกับ multi-task (X5)

ผู้เขียน: lemasc

## In plain words
เทรน SegFormer-B2 ธรรมดา (ไม่มี attribute head) ด้วย seed 1 ครบ 40,000 iteration บน RTX 4070 เป็น run อ้างอิงของ X5
test mIoU: LIP **0.6156**, CIHP **0.6312**, DFMM **0.8404** (eval-v2, `best.pt` step 40000)
เทียบกับ X5 (multi-task, seed และ GPU เดียวกัน): mIoU ต่างกันไม่เกิน 0.0009 ในทุก test set (X5 ต่ำกว่าเล็กน้อยทั้งสามชุด)
**ข้อสรุป: การเพิ่ม attribute head ไม่ทำให้ segmentation แย่ลงจนวัดได้** และไม่ได้ช่วยให้ดีขึ้นด้วย
แต่มีเพียงคู่เดียว (1 seed ต่อฝั่ง) จึงไม่ใช่ผลทางสถิติ

ตัวเลขทุกตัวมาจากไฟล์ใน run folder (`meta.json`, `log.jsonl`, `eval/eval-v2/*/metrics.json`)
ตัวเลข X5 มาจาก [`2026-11-08-X5-segformer-b2-mt.md`](2026-11-08-X5-segformer-b2-mt.md) และ run folder ของ X5 ไม่มีค่าประมาณ

## การตีความ
- **ความต่าง X5 กับ X6 เล็กมาก** mIoU ต่างกัน 0.0002–0.0009 ต่อ test set และ 0.0006 ในค่าเฉลี่ย 12 คลาส
  ขนาดนี้เล็กกว่าความต่างที่เห็นระหว่าง X4 กับ X6 (สูงสุด 0.0021 บน DFMM) ซึ่งต่างกันที่ seed และ GPU
  จึงบอกได้ว่า **ไม่เห็นผลเสียต่อ segmentation จากการเพิ่ม attribute head** ที่ขนาดที่ตรวจจับได้ด้วยข้อมูลชุดนี้
- **ก็ไม่เห็นผลดีเช่นกัน** X5 ต่ำกว่า X6 เล็กน้อยทั้งสาม test set แต่ทิศทางเดียวกันสามครั้งจาก 1 คู่ไม่พอจะอ้างว่า attribute head ทำให้แย่ลง
  ส่วน val ตอนจบ X5 สูงกว่า X6 (0.7014 เทียบกับ 0.6989) ซึ่งสวนทางกับ test จึงยิ่งแสดงว่าเป็นความแกว่งของ run
- **ความต่างรายคลาสใหญ่สุดอยู่ที่คลาสที่ IoU ต่ำหรือมีพิกเซลน้อย** เช่น `skirt` บน LIP (X5 ต่ำกว่า 0.0289), `dress` บน LIP (X5 สูงกว่า 0.0180)
  และ `accessory` บน DFMM (X5 ต่ำกว่า 0.0146) ทิศทางไม่คงที่ข้าม test set จึงดูเป็นความแกว่งมากกว่าผลของ attribute
  ไม่ได้ตรวจจริง (ไม่ได้วัดความแกว่งรายคลาสระหว่าง seed)
- **ต้นทุนของ multi-task ต่ำ** พารามิเตอร์เพิ่ม 1.0% เวลาเทรนต่างกัน 0.3%
- **คำตอบสำหรับ rubric (E1):** โมเดลเดียวทำสองงานได้ segmentation ไม่เสียเมื่อเทียบ run เดียวกันที่ไม่มี head
  และ attribute ทำได้ macro-F1 0.8036 เทียบ 0.3310 ของ majority baseline (รายละเอียดใน report ของ X5)

## สิ่งที่ยังไม่รู้
- ความแกว่งระหว่าง seed ที่แท้จริงของ SegFormer-B2 บน GPU เดียวกัน (มี seed 1 สองค่า คือ X5 กับ X6 ที่ต่างกันที่ head เท่านั้น ไม่ใช่การซ้ำ seed เดียวกัน)
- ผลของ multi-task จะเป็นบวกหรือลบถ้าใช้ `loss_weight` อื่น (ใช้ 0.1 ค่าเดียว ไม่ได้จูน)
- attribute head ช่วยลด error ระหว่างคลาสที่เกี่ยวกับ attribute (เช่น `outer` กับ `upper`) หรือไม่ ยังไม่ได้วิเคราะห์ error
- ผลที่ seed อื่นหรือ GPU อื่น (X4 กับ X6 ต่างกันทั้งคู่ จึงแยกไม่ได้ว่าความต่างมาจากอะไร)
